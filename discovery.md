Building a visualizer program. There are all kinds of different visualizations/3Dgraphics applications, but I've only ever used TD, and it has a nice and simple interface and flow that separates out different properties and concepts of general digital graphics: 3D geometry, textures, point clouds, channels, etc. Also, TD is heavily generative/procedural, so you set up the conditions and then just let it go, and the patterns/visuals can go on indefinitely. Also, one thing with TD that I'm not sure exists in other similar digital graphics apps is the ability and ease of connecting to various controllers/modulators: audio, OSC data, video, etc. You can also use Python scripts, and I think JS? I'm not exactly sure if this would make a difference, but there are some TD networks that turn my computer into an oven, so I wonder if being able to be more surgical/customizable with a custom app might provide some options to get more performance out of a computer. Doing this, for me, is already a fuck-ton, but if it matters, I would want this to be a part of a tool/workflow for generative VR environments, mostly abstract visuals and soundscapes, and be able to deliver those environments to other VR setups. You mentioned making an app just for this is how you'd do it, if I remember correctly.
